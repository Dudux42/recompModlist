# Attribution and provenance

This mod is independently implemented from audited factual data.

- Pokemon Yellow Legacy v1.0.10 by SmithPlaysPokemon and the Yellow Legacy
  team is the factual source for encounter, base-stat, and learnset changes and
  for the selected alternative evolution levels.
- The supplied v1.0.10 ROM is used only as a verification oracle and is never
  distributed.
- The public Yellow Legacy source tag is used to verify factual values. Its
  implementation text is not copied into this mod.
- Gen1Recomp 0.1.71 provides the public mod API and test harness.
- The installed `yellow_legacy_changes` mod is treated as a read-only mapping
  reference, not copied as the implementation source.

See the workspace's `BALANCES_MOD_PLAN.md` for the active scope and
`YELLOW_LEGACY_GATE0_EVIDENCE.md` for the preserved source audit.
