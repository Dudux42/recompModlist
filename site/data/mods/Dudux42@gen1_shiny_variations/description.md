# Gen1 Shiny Variations

Adds independently selectable alternate shiny designs for each Gen 1 Pokémon.
The initial Stable build supplies Bulbasaur Variant 1 using its complete Gen 5
front normal-and-special animation loop; every other species remains Default
until a corresponding user-approved asset is supplied. Gen1 Battle Art
Replacer retains all loading, animation, filtering, caching, and fallback
ownership.
